一款「红果式」免费短剧运营系统完整源码。
不是单页模板，是：用户端 + App + 运营后台 + Go 业务中台 一套闭环。

适合：
• 想快速上线短剧站 / App 的团队
• 出海短剧、英语/东南亚市场试水
• 工作室接私活白标换皮、二次开发

────────────────
【一、技术栈总览】
────────────────

■ 后端（Go）
 语言/框架：Go · Gin
 ORM/库：GORM
 数据：MySQL 5.7+ · Redis
 鉴权：JWT
 媒体：播放地址签名防盗链（mp4 / HLS）
 存储：腾讯云 COS 等对象存储可配
 支付：支付宝（证书/密钥）· PayPal（USD）· 聚合支付 · 模拟支付开关
 部署：Linux amd64 单二进制 + 安装向导 + systemd/启停脚本
 无需在服务器安装 Go / Node / Flutter

■ 运营后台（Web）
 Vue 3 + Vite + 管理端组件库
 角色：超管 / 运营 / 财务 / 内容
 配置进库，后台改完即生效

■ 用户 H5
 Vue 3 + Vite
 可投放获客，也可引导下载 App
 与 App 共用同一套 API

■ 移动端 App
 Flutter（Android + iOS 同一套代码）
 竖屏沉浸播放、上下滑切集、预加载
 国区/语言包与后端 X-Lang 联动

────────────────
【二、产品功能（按模块）】
────────────────

【1】播放与内容
• 首页推荐流：新剧 / 高分 / 推荐 Tab
• 剧场：分类、筛选、排行、新剧、高分，封面热度
• 剧详情：简介、选集网格、追剧、续播到指定集
• 竖屏播放：点赞/收藏/评论/弹幕/分享
• 解锁策略：免费集 · 看广告解锁 · 钻石解锁单集 · VIP 会员畅看
• 搜索、观看历史、收藏、点赞、追剧

【2】会员与钱包
• VIP 套餐开通/续费（支付宝 / PayPal USD 等）
• 钻石充值与消费
• 金币账户、现金余额（USD 展示）
• 卡密兑换
• 流水明细（金币/现金）

【3】赚钱增长（核心卖点）
• 每日签到领金币
• 看剧时长档位奖励（如 5/10/20/30 分钟）
• 开宝箱、看广告、吃饭/睡觉/红包雨等任务
• 金币兑换现金
• 提现档位（USD）+ 审核流（通过/驳回）

【4】邀请裂变
• 邀请码 / 链接 / 二维码
• 一级、二级充值返利（比例后台可配，默认 10% / 5%）
• 好友列表与收益明细

【5】出海与本地化
• 多国区思路（CN/US/JP/VN/ID/TH/KR/SG/GB/AU 等）
• H5 + App 多语言包（中/英/日/越/印尼/泰/韩…）
• 货币统一 USD（$），PayPal 结算 USD

【6】运营后台
• 数据看板
• 短剧/分集：MP4 上传、HLS zip、免费集数、会员畅看、钻石价、广告解锁开关
• 用户管理、评论管理
• 订单、流水、钻石套餐、VIP 套餐
• 提现审核、提现档位与说明配置
• 任务/签到/宝箱、邀请返利文案
• 自有广告位、公告
• 站点/H5/协议/存储/支付/广告SDK/AI/管理员

────────────────
【三、架构说明】
────────────────

 Flutter App ─┐
 Vue H5 ─┼─► Go API（Gin） ─► MySQL / Redis
 Vue Admin ─┘ │
 ├─► 对象存储 COS（封面/视频）
 ├─► 支付宝 / PayPal 回调
 └─► 播放票据签名媒体

安装：无 config 时先进安装向导 → 填库与 Redis → 自动建表种子数据 → 切业务服务。
升级：启动 AutoMigrate 补字段，不覆盖已有运营配置。

【七、常见问题】
────────────────

Q：是成品能跑吗？
A：是完整业务系统，有安装向导和文档；可约演示验证。

Q：只有 H5 行不行？
A：可以先上 H5，App 同源接同一后端，随时补上。

Q：提现自动打款吗？
A：默认财务审核后线下打款，降低未签约代付风险；可二开接代付。

Q：片源哪里来？
A：系统是平台能力；片源版权需您合规自备或采购。

Q：能改名换皮吗？
A：支持白标：站点名/Logo/域名/主题资源可替换。
